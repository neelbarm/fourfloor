# Style profiles

Aggregate profiles produced by `fourfloor learn`. Apply one with
`fourfloor remix song.mp3 --style styles/klickaud-refs.json`.

- **`klickaud-refs.json`** — learned from five commercial house/bounce remixes
  (DJ-edit "free download" releases). Aggregate numbers only: no filenames, no
  audio, nothing derived from the recordings beyond these summary statistics.
  Note the `peak_db` of +1.24 dBFS — those masters are limited hard enough that
  the decoded signal overshoots full scale, which is normal for this genre and
  is *not* a target fourfloor tries to hit. fourfloor masters to −1 dBFS.
